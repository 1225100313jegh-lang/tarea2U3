# Tanda Doloreña

Aplicación Flutter para administrar tandas, participantes, aportaciones y cierres de ronda.

## Desarrollo

```bash
flutter pub get
flutter test
```

## APK release

Antes de compilar, copia `android/key.properties.example` como `android/key.properties`,
configura las credenciales del keystore y coloca el archivo `.jks` indicado.

```bash
flutter build apk --release
```
